Privacy Policy for Wallet Segura Extension

Effective Date: October 12, 2026

At Wallet Segura, we take your privacy and the security of your credentials very seriously. This Privacy Policy describes how the Wallet Segura Extension handles data and ensures your information remains secure within your local environment.

🔒 Zero-Knowledge & Local Storage Architecture:
Wallet Segura Extension does NOT collect, store, or transmit any personal data, passwords, or credentials to external servers. All sensitive data is kept locally on your machine.

1. Data Encryption and Storage

All passwords and sensitive user credentials managed by the Wallet Segura ecosystem are stored exclusively inside a local, heavily encrypted vault file managed by our companion native Windows Application. The browser extension does not have direct access to this file, ensuring a strong cryptographic boundary.

2. Local Communications and Permissions

To function properly, the extension requests the minimum necessary permissions in accordance with Manifest V3 standards:

  • activeTab & scripting: Used strictly to securely detect login forms and autofill credentials into web fields following an explicit user action.
  • storage: Used strictly to save user preferences and the secure local pairing key required to establish a trust relationship with the Windows desktop application.
  • Host Permission (http://127.0.0*): This permission is used solely to communicate locally with the native Wallet Segura Windows Application running on your loopback address (localhost). No data ever leaves your computer via external networks.

3. The Pairing Mechanism

To prevent unauthorized access, communication between the extension and the native Windows application requires a unique pairing key. This ensures that only your trusted browser extension can request credentials from your encrypted local vault.

4. Third-Party Sharing

We do not collect, sell, trade, or transfer any information to third parties. The extension contains no analytics trackers, tracking cookies, or telemetry software.
